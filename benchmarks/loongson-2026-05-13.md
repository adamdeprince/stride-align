# Loongson Benchmark Notes - 2026-05-13

These results are Loongson-only and should not be mixed with the x86 benchmark
summary. The source tree was built on `loongson` from the same git branch using
Python 3.13.13, GCC 15.2.0, and CMake 4.3.2.

Raw artifacts:

- `benchmarks/loongson-score-native-2026-05-13.csv`: native `generic`, `swar`, `linux_loongarch64_lsx`, and `linux_loongarch64_lasx` score-only rows, including `1:1` and `1:many`.
- `benchmarks/loongson-score-1to1-parasail-2026-05-13.csv`: direct `sw-score`/`nw-score` `1:1` comparison against a patched generic LoongArch parasail build.
- `benchmarks/loongson-path-native-2026-05-13.csv`: native path/CIGAR rows with timing split, no parasail.
- `benchmarks/loongson-sw-farrar-exactfill-baseline-2026-05-14.csv`: focused linear `sw-farrar-score` baseline before exact-fill hooks.
- `benchmarks/loongson-sw-farrar-exactfill-study-2026-05-14.csv`: focused linear `sw-farrar-score` run after exact-fill hooks.

Parasail status:

- Upstream `pip install parasail` does not work on this LoongArch machine.
- Building required a patched source tree: `cpuid.c` needed LoongArch treated as a non-x86 stub target.
- The resulting parasail build is generic LoongArch, not LSX/LASX optimized.
- Parasail's Python profile API returned NULL profiles, so benchmark fallback used direct score calls only.
- Parasail trace/CIGAR was not used in the Loongson artifact because the patched generic Python wrapper did not expose usable traceback CIGAR objects.

Score-only results:

- LSX is consistently useful for native score kernels: median native score speedup is `3.93x` over generic, with best rows around `8.86x`.
- LASX is stronger: median native score speedup is `6.79x` over generic, with best rows around `16.05x`.
- Against patched generic parasail direct score rows, LSX wins all 16 comparable rows with `5.31x` geomean speedup.
- Against patched generic parasail direct score rows, LASX wins all 16 comparable rows with `7.52x` geomean speedup.
- Exact-fill linear `sw-farrar-score` hooks transfer well from the NEON lesson. In the focused 2026-05-14 run, LSX improved `1.73x` geomean and LASX improved `1.63x` geomean over the pre-change focused baseline.
- After exact-fill hooks, focused linear `sw-farrar-score` is about `10.24x` generic on LSX and `17.50x` generic on LASX.

Path/CIGAR results:

- Native affine CIGAR/path rows benefit from LSX/LASX; the best LASX rows are about `4.32x` generic.
- Native linear SW path/CIGAR rows are the weak point. LSX drops as low as `0.34x` generic and LASX as low as `0.48x` generic.
- This points at trace-table/materialization traffic rather than raw score DP throughput.

Recommended next Loongson work:

1. Keep exact-fill LSX/LASX score hooks enabled; they are a large score-only win.
2. Do a Loongson-specific linear SW trace/CIGAR redesign instead of reusing the current fixed-kernel path materialization.
3. Start with LASX width16/width32 trace traffic reduction, then port the measured structure to LSX.
4. Add a native Loongson microbench/perf path before doing instruction scheduling work.
5. Treat parasail as a generic comparison on Loongson unless a maintained LSX/LASX parasail port is added.
