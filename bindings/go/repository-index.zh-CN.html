首选源码安装：它由 Go 模块校验和保护，并在应用程序的实际目标上编译。

预编译模式仍需要 cgo、C 编译器与 pkg-config，但不会调用 C++ 编译器。Linux 软件包包含静态 C++ 运行库并以 glibc 2.28 为基线；安装器会在解压前验证 SHA-256。

从源代码安装（推荐）

go get github.com/adamdeprince/stride-align/bindings/go@main

安装预编译回退

go run github.com/adamdeprince/stride-align/bindings/go/cmd/stridealign-prebuilt@main
