stride-align for R

The portable installation path builds stridealign from source:

install.packages(
    "stridealign",
    repos = "https://distribution.goblinreactor.com/stride-align/R",
    type = "source"
)

A prebuilt arm64 binary is also available specifically for Homebrew R 4.6 on macOS 26 or newer:

install.packages(
    "stridealign",
    repos = "https://distribution.goblinreactor.com/stride-align/R",
    type = "mac.binary.big-sur-arm64"
)

The binary links against Homebrew's R installation. Users of the CRAN macOS framework build, older macOS releases, and other platforms should use the source command above.
