A Memgraph container on macOS runs a Linux server process. Use a package matching that container architecture, not the macOS host package.

Both Linux packages target the manylinux_2_28 ABI (glibc 2.28 or newer). The AVX2 package also requires an x86-64-v3 processor; use generic when the server CPU is unknown.

Install into a native Linux server

sudo install -m 0755 stride_align-0.6.0.so \
  /usr/lib/memgraph/query_modules/stride_align.so

# Restart Memgraph, or reload the module from Cypher:
echo 'CALL mg.load("stride_align");' | mgconsole

Mount into a container

podman run --rm -p 7687:7687 \
  -v "$PWD/stride_align-0.6.0.so:/usr/lib/memgraph/query_modules/stride_align.so:ro" \
  docker.io/memgraph/memgraph:3.10.1

The module provides 90 scalar Cypher functions and a row-streaming cdist procedure. See the cross-language API, the complete Memgraph catalog, the machine-readable manifest, or all checksums.
