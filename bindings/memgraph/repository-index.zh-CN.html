可用软件包

分发文件名带有版本号。安装时请命名为 stride_align.so，这样 Memgraph 才会注册 stride_align 命名空间。

平台CPU 软件包文件验证
macOS arm64 13+NEON / Apple M1 基线下载SHA-256构建测试
Linux x86-64generic / SSE2 基线下载SHA-256运行测试
Linux x86-64AVX2 / x86-64-v3下载SHA-256运行测试

macOS 上的 Memgraph 容器运行 Linux 服务器进程；应使用与容器体系结构匹配的软件包，而不是 macOS 主机软件包。

两个 Linux 软件包都采用 manylinux_2_28 ABI（glibc 2.28 或更新版本）。AVX2 软件包还要求 x86-64-v3 处理器；不确定服务器 CPU 时请使用 generic 软件包。

安装到原生 Linux 服务器

sudo install -m 0755 stride_align-0.6.0.so \
  /usr/lib/memgraph/query_modules/stride_align.so

# 重启 Memgraph，或从 Cypher 重新加载模块：
echo 'CALL mg.load("stride_align");' | mgconsole

挂载到容器

podman run --rm -p 7687:7687 \
  -v "$PWD/stride_align-0.6.0.so:/usr/lib/memgraph/query_modules/stride_align.so:ro" \
  docker.io/memgraph/memgraph:3.10.1

该模块提供 90 个标量 Cypher 函数以及按行流式返回的 cdist 过程。请参阅跨语言编程接口、完整 Memgraph 目录、机器可读清单或 SHA-256 校验和。
