# Translation rules used

- Add the language carousel near the top of every README.
- Preserve Markdown structure.
- Preserve every fenced code block and terminal-output block exactly, including prompts, command lines, file paths, URLs, package names, API names, flags, function names, benchmark numbers, and BibTeX.
- Preserve the Bible verse text in English. The explanatory prose around it may be translated; the verse quotations and sample-output verse lines are not translated.
- Preserve true identifiers and proper technical names: `stride-align`, Python, C++, NumPy, Loongson, LoongArch, SIMD, LASX, Smith-Waterman, Needleman-Wunsch, CIGAR, SAM/BAM, nanobind, Parasail, and similar names.
- Translate ordinary prose-level technical language: objects, library, implementation, backend dispatch, traceback, preprocessing, token streams, path functions, benchmark, profiling, frame pointers, and similar terms.
- Keep the voice practical, engineer-facing, and dry rather than corporate.
