Release 0.6.0 · Apache-2.0

Unicode string comparison and sequence alignment.

stride-align provides one native C++ implementation of edit distance, similarity, biological alignment, phonetic encoding, and time-series alignment. It is available from Python, R, DuckDB, PostgreSQL, and Memgraph without changing the underlying scoring definitions.

Getting started

Install, verify, then move from one pair to a corpus.

Every step has a language selector. They stay synchronized, so choose the interface wherever you are reading and the complete walkthrough changes with it.

Install the selected interface.

Each interface exposes the native stride-align algorithms. Database extensions are selected or built for the server version, platform, and SIMD level.

PythonInstallation guide ↗
python3 -m pip install stride-align
Download POWER8 and LoongArch Python wheels→

Architecture packages. Self-hosted CPython 3.12–3.14 wheels are available for POWER8 and LoongArch. Because PyPI does not index linux_loongarch64 wheels, LoongArch users should identify old-world or new-world and install the matching v0.6.0 wheel from the download page. Other platforms can use the command above.

RPackage repository ↗
R -q -e 'install.packages(
  "stridealign",
  repos="https://distribution.goblinreactor.com/stride-align/R",
  type="source"
)'

The hosted source package is the portable installation. The repository also identifies the narrower environments for which a binary package is available.

DuckDB SQL, orchestrated by PythonExtension packages ↗
python3 -m pip install duckdb==1.5.5

# Download the extension matching DuckDB 1.5.5,
# your platform, and your CPU package, then set:
export STRIDE_ALIGN_DUCKDB_EXTENSION=/absolute/path/to/stride_align.0.6.0.duckdb_extension
Download the DuckDB extension package→

DuckDB extensions are tied to the DuckDB ABI. Choose generic, AVX2, AVX-512, or NEON from the package index rather than loading an ISA your machine does not support.

PostgreSQL 16–18, orchestrated by PythonPGXS build guide ↗
python3 -m pip install "psycopg[binary]>=3.2"

make -C bindings/postgres \
  PG_CONFIG="$(command -v pg_config)" \
  STRIDE_ALIGN_POSTGRES_SIMD=native
sudo make -C bindings/postgres \
  PG_CONFIG="$(command -v pg_config)" install

psql "$STRIDE_ALIGN_POSTGRES_DSN" \
  -c 'CREATE EXTENSION stride_align'

The PGXS extension supports PostgreSQL 16, 17, and 18. Build once for each server major and choose a SIMD profile supported by that server machine.

Memgraph, orchestrated by PythonQuery-module packages ↗
python3 -m pip install "gqlalchemy>=1.9"

# Download the module matching Memgraph 3.10.1,
# the server platform, and its CPU profile, then install it as:
sudo install -m 0755 stride_align-0.6.0.so \
  /usr/lib/memgraph/query_modules/stride_align.so

export STRIDE_ALIGN_MEMGRAPH_HOST=127.0.0.1
export STRIDE_ALIGN_MEMGRAPH_PORT=7687
Download the Memgraph query module→

Use the module matching the Memgraph process, not merely the client machine. Linux generic and AVX2 packages are runtime tested; the native macOS arm64 package targets macOS 13 or later.

Fuzzy-match a paraphrase against a corpus.

An exact substring search fails because the query and target use different wording. This example scores one query against 31,102 records and returns the highest-scoring complete record.

A note from the author

I apologize to anyone who finds the use of Christian scripture here exclusionary or offensive. I am not using religious texts to make a religious statement or push an agenda. This demonstration needs multiple large public-domain documents with the same meaning phrased differently, and Bible translations happen to fit that requirement freakishly well.

Python batch APIpython3 bible.py
from pathlib import Path
from urllib.request import urlretrieve

import stride_align as sa

corpus = Path("kjv.txt")
if not corpus.exists():
    urlretrieve("https://openbible.com/textfiles/kjv.txt", corpus)

rows = [
    line.split("\t", 1)
    for line in corpus.read_text(encoding="utf-8-sig").splitlines()
    if "\t" in line
]
references, verses = zip(*rows, strict=True)

query = (
    "The earth will mourn, and the heavens will lament from above. "
    "For I have spoken, I have decided, and I have not regretted. "
    "Neither will I be turned away from it."
)
scores = sa.needleman_wunsch_normalized_scores(
    query.lower(),
    [verse.lower() for verse in verses],
)
best = int(scores.argmax())

print(f"{references[best]}\t{verses[best]}")
print(f"score: {float(scores[best]):.6f}")

One Python call scores the full target sequence. The prepared query is reused across the batch.

Save as bible_duckdb.pypython3 bible_duckdb.py
import os
from pathlib import Path
from urllib.request import urlretrieve

import duckdb

corpus = Path("kjv.txt")
if not corpus.exists():
    urlretrieve("https://openbible.com/textfiles/kjv.txt", corpus)

db = duckdb.connect(config={"allow_unsigned_extensions": "true"})
extension = os.environ["STRIDE_ALIGN_DUCKDB_EXTENSION"].replace("'", "''")
db.execute(f"LOAD '{extension}'")

db.execute(
    """
    CREATE OR REPLACE TABLE demo_bible AS
    SELECT trim(reference) AS reference, trim(verse) AS verse
    FROM read_csv(
        ?,
        delim = '\t',
        header = false,
        skip = 2,
        columns = {'reference': 'VARCHAR', 'verse': 'VARCHAR'},
        quote = '',
        escape = ''
    )
    WHERE reference IS NOT NULL
      AND verse IS NOT NULL
      AND trim(verse) != ''
    """,
    [str(corpus.resolve())],
)

query = (
    "The earth will mourn, and the heavens will lament from above. "
    "For I have spoken, I have decided, and I have not regretted. "
    "Neither will I be turned away from it."
)

reference, verse, score = db.execute(
    """
    WITH corpus AS (
        SELECT
            list(reference ORDER BY reference, verse) AS reference_values,
            list(verse ORDER BY reference, verse) AS verse_values,
            list(lower(verse) ORDER BY reference, verse) AS normalized_verses
        FROM demo_bible
    ), matched AS (
        SELECT
            reference_values,
            verse_values,
            stride_extract_best(
                lower(?),
                normalized_verses,
                'needleman_wunsch_normalized'
            ) AS best_match
        FROM corpus
    )
    SELECT
        reference_values[cast(best_match.index AS BIGINT) + 1] AS reference,
        verse_values[cast(best_match.index AS BIGINT) + 1] AS verse,
        best_match.score AS score
    FROM matched
    """,
    [query],
).fetchone()

print(f"{reference}\t{verse}")
print(f"score: {score:.6f}")

The Python orchestration has the same cache-if-present behavior as the Python example, but loads the corpus into DuckDB. SQL forms one ordered candidate list, then stride_extract_best runs stride-align's optimized Needleman–Wunsch batch and top-one path.

Save as bible_postgres.pypython3 bible_postgres.py
import os
from pathlib import Path
from urllib.request import urlretrieve

import psycopg

corpus = Path("kjv.txt")
if not corpus.exists():
    urlretrieve("https://openbible.com/textfiles/kjv.txt", corpus)

rows = [
    (reference.strip(), verse.strip())
    for line in corpus.read_text(encoding="utf-8-sig").splitlines()
    if "\t" in line
    for reference, verse in [line.split("\t", 1)]
    if verse.strip()
]
query = (
    "The earth will mourn, and the heavens will lament from above. "
    "For I have spoken, I have decided, and I have not regretted. "
    "Neither will I be turned away from it."
)

with psycopg.connect(os.environ["STRIDE_ALIGN_POSTGRES_DSN"]) as db:
    db.execute(
        "CREATE TEMP TABLE demo_bible "
        "(reference text, verse text) ON COMMIT DROP"
    )
    with db.cursor().copy(
        "COPY demo_bible (reference, verse) FROM STDIN"
    ) as copy:
        for row in rows:
            copy.write_row(row)

    reference, verse, score = db.execute(
        """
        WITH corpus AS (
            SELECT
                array_agg(reference ORDER BY reference, verse) AS references,
                array_agg(verse ORDER BY reference, verse) AS verses,
                array_agg(lower(verse) ORDER BY reference, verse) AS normalized
            FROM demo_bible
        ), matched AS (
            SELECT references, verses, stride_extract_best(
                lower(%s), normalized, 'needleman_wunsch_normalized'
            ) AS best_match
            FROM corpus
        )
        SELECT
            references[((best_match->>'index')::integer) + 1],
            verses[((best_match->>'index')::integer) + 1],
            (best_match->>'score')::double precision
        FROM matched
        """,
        (query,),
    ).fetchone()

print(f"{reference}\t{verse}")
print(f"score: {score:.6f}")

Python uses PostgreSQL's COPY protocol to load the corpus. One ordered text[] then enters stride_extract_best, preserving stride-align's optimized batch and top-one path inside the server.

import os
from pathlib import Path
from urllib.request import urlretrieve

from gqlalchemy import Memgraph

corpus = Path("kjv.txt")
if not corpus.exists():
    urlretrieve("https://openbible.com/textfiles/kjv.txt", corpus)

rows = [
    {"reference": reference.strip(), "verse": verse.strip()}
    for line in corpus.read_text(encoding="utf-8-sig").splitlines()
    if "\t" in line
    for reference, verse in [line.split("\t", 1)]
    if verse.strip()
]
query = (
    "The earth will mourn, and the heavens will lament from above. "
    "For I have spoken, I have decided, and I have not regretted. "
    "Neither will I be turned away from it."
)

db = Memgraph(
    host=os.environ.get("STRIDE_ALIGN_MEMGRAPH_HOST", "127.0.0.1"),
    port=int(os.environ.get("STRIDE_ALIGN_MEMGRAPH_PORT", "7687")),
)
db.execute("MATCH (v:StrideAlignDemoVerse) DETACH DELETE v")
for offset in range(0, len(rows), 1000):
    db.execute(
        """UNWIND $rows AS row
        CREATE (:StrideAlignDemoVerse {
            reference: row.reference,
            verse: row.verse,
            normalized: toLower(row.verse)
        })""",
        {"rows": rows[offset : offset + 1000]},
    )

best = next(db.execute_and_fetch(
    """MATCH (verse:StrideAlignDemoVerse)
    WITH verse,
         stride_align.needleman_wunsch_normalized_score(
             $query, verse.normalized
         ) AS score
    RETURN verse.reference AS reference, verse.verse AS verse, score
    ORDER BY score DESC, reference, verse
    LIMIT 1""",
    {"query": query.lower()},
))

print(f"{best['reference']}\t{best['verse']}")
print(f"score: {best['score']:.6f}")

Apply the same operation to a spell checker.

This intentionally small example ignores punctuation, frequency, context, and proper nouns. Its purpose is to show one token compared with an entire dictionary through a native batch path or database record stream.

Python batch APIprintf '...' | python3 spell.py
import sys
from pathlib import Path

import stride_align as sa

paths = [
    Path("/usr/share/dict/words"),
    Path("/usr/dict/words"),
    Path("/var/lib/dict/words"),
    Path("/etc/dictionaries-common/words"),
]
dictionary_path = next(path for path in paths if path.is_file())
words = list(dict.fromkeys(
    word.strip().lower()
    for word in dictionary_path.read_text(errors="ignore").splitlines()
    if word.strip()
))

def correct(token):
    scores = sa.needleman_wunsch_normalized_scores(token, words)
    return words[int(scores.argmax())]

tokens = sys.stdin.readline().lower().split()
print(" ".join(correct(token) for token in tokens))

Each token produces one batch call across the dictionary; the scoring loop stays in the native library.

import os
import sys
from pathlib import Path

import duckdb

paths = [
    Path("/usr/share/dict/words"),
    Path("/usr/dict/words"),
    Path("/var/lib/dict/words"),
    Path("/etc/dictionaries-common/words"),
]
dictionary_path = next((path for path in paths if path.is_file()), None)
if dictionary_path is None:
    raise FileNotFoundError("no system dictionary found")

db = duckdb.connect(config={"allow_unsigned_extensions": "true"})
extension = os.environ["STRIDE_ALIGN_DUCKDB_EXTENSION"].replace("'", "''")
db.execute(f"LOAD '{extension}'")

db.execute(
    """
    CREATE OR REPLACE TABLE demo_dictionary AS
    SELECT DISTINCT lower(trim(word)) AS word
    FROM read_csv(
        ?,
        delim = '\x1f',
        header = false,
        columns = {'word': 'VARCHAR'},
        quote = '',
        escape = ''
    )
    WHERE word IS NOT NULL AND trim(word) != ''
    """,
    [str(dictionary_path.resolve())],
)

line = sys.stdin.readline()
corrected = db.execute(
    """
    WITH dictionary AS (
        SELECT list(word ORDER BY word) AS words
        FROM demo_dictionary
    ), input_tokens AS (
        SELECT position, token
        FROM unnest(string_split(lower(?), ' '))
             WITH ORDINALITY AS tokens(token, position)
        WHERE token != ''
    ), matched AS (
        SELECT
            position,
            stride_extract_best(
                token,
                words,
                'needleman_wunsch_normalized'
            ) AS best_match
        FROM input_tokens
        CROSS JOIN dictionary
    )
    SELECT coalesce(
        string_agg(best_match.target, ' ' ORDER BY position),
        ''
    )
    FROM matched
    """,
    [line],
).fetchone()[0]

print(corrected)

Python finds the dictionary, sideloads the extension, and submits one query. DuckDB owns tokenization and reconstruction; each token is matched through stride-align's one-to-many top-one operation.

import os
import sys
from pathlib import Path

import psycopg

paths = [
    Path("/usr/share/dict/words"),
    Path("/usr/dict/words"),
    Path("/var/lib/dict/words"),
    Path("/etc/dictionaries-common/words"),
]
dictionary_path = next((path for path in paths if path.is_file()), None)
if dictionary_path is None:
    raise FileNotFoundError("no system dictionary found")

words = sorted({
    word.strip().lower()
    for word in dictionary_path.read_text(errors="ignore").splitlines()
    if word.strip()
})
tokens = sys.stdin.readline().lower().split()

with psycopg.connect(os.environ["STRIDE_ALIGN_POSTGRES_DSN"]) as db:
    db.execute(
        "CREATE TEMP TABLE demo_dictionary (word text) ON COMMIT DROP"
    )
    with db.cursor().copy(
        "COPY demo_dictionary (word) FROM STDIN"
    ) as copy:
        for word in words:
            copy.write_row((word,))

    corrected = db.execute(
        """
        WITH dictionary AS (
            SELECT array_agg(word ORDER BY word) AS words
            FROM demo_dictionary
        ), input_tokens AS (
            SELECT token, position
            FROM unnest(%s::text[]) WITH ORDINALITY AS input(token, position)
        ), matched AS (
            SELECT position, stride_extract_best(
                token, words, 'needleman_wunsch_normalized'
            ) AS best_match
            FROM input_tokens
            CROSS JOIN dictionary
        )
        SELECT coalesce(
            string_agg(best_match->>'target', ' ' ORDER BY position),
            ''
        )
        FROM matched
        """,
        (tokens,),
    ).fetchone()[0]

print(corrected)

Python loads the dictionary through COPY and submits the token list once. PostgreSQL applies stride-align's native one-to-many top-one operation to each token and reconstructs the sentence in SQL.

import os
import sys
from pathlib import Path

from gqlalchemy import Memgraph

paths = [
    Path("/usr/share/dict/words"),
    Path("/usr/dict/words"),
    Path("/var/lib/dict/words"),
    Path("/etc/dictionaries-common/words"),
]
dictionary_path = next((path for path in paths if path.is_file()), None)
if dictionary_path is None:
    raise FileNotFoundError("no system dictionary found")

words = sorted({
    word.strip().lower()
    for word in dictionary_path.read_text(errors="ignore").splitlines()
    if word.strip()
})
tokens = sys.stdin.readline().lower().split()

db = Memgraph(
    host=os.environ.get("STRIDE_ALIGN_MEMGRAPH_HOST", "127.0.0.1"),
    port=int(os.environ.get("STRIDE_ALIGN_MEMGRAPH_PORT", "7687")),
)
db.execute("MATCH (w:StrideAlignDemoWord) DETACH DELETE w")
for offset in range(0, len(words), 1000):
    db.execute(
        """UNWIND $words AS word
        CREATE (:StrideAlignDemoWord {value: word})""",
        {"words": words[offset : offset + 1000]},
    )

rows = db.execute_and_fetch(
    """UNWIND range(0, size($tokens) - 1) AS position
    MATCH (word:StrideAlignDemoWord)
    WITH position, word.value AS candidate,
         stride_align.needleman_wunsch_normalized_score(
             $tokens[position], word.value
         ) AS score
    ORDER BY position, score DESC, candidate
    WITH position, collect(candidate)[0] AS correction
    RETURN position, correction
    ORDER BY position""",
    {"tokens": tokens},
)

print(" ".join(row["correction"] for row in rows))
